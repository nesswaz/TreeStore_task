# TreeStore_task

# Тестовое задание OOO «Mstroj» — класс TreeStore (C++)

Решение тестового задания от компании **ООО «МСтрой»**.
* **Ссылка на исходное задание:** [Каталог Hexlet (ooo-mstroj)](https://github.com/Hexlet/ru-test-assignments/blob/main/backend/ooo-mstroj/README.md)

## Что сделано
Задание я реализовала на языке **C++**. Чтобы поиск элементов работал быстро и без повторного перебора всего массива в цикле, при создании объекта `TreeStore` все элементы сохраняются в словари `std::map`.

Структура проекта:
* **`TreeStoreH.h`** — заголовочный файл со структурой элемента `Item` и объявлением класса `TreeStore`.
* **`TreeStoreModule.cpp`** — реализация конструктора и четырёх методов (`getAll`, `getItem`, `getChildren`, `getAllParents`), а также защита от ошибок во входных данных (отрицательные `id`, дубликаты `id`, ссылки на самого себя и циклы родителей).
* **`TreeStoreMain.cpp`** — проверка работы всех методов на примере из задания компании и граничных случаях.

## Что не делалось
* Код написан на C++ вместо Python.
* Не использовались внешние библиотеки для автотестов — все проверки запускаются сразу в `TreeStoreMain.cpp`.

## Как запустить
Открыть папку с файлами в терминале (PowerShell / командной строке) и выполнить две команды:

1. Скомпилировать программу:
```bash
g++ TreeStoreMain.cpp TreeStoreModule.cpp -o program.exe
```
2. Запустить:
```bash
./program.exe
```
